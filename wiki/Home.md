# shell-next

Persistent asynchronous Bash, PowerShell, and cmd sessions for Python 3.14+.
Use one interface for session state, command ownership, interactive input,
bounded output, and deterministic application tests.

```console
python -m pip install shell-next
```

- [Getting started](https://github.com/gokurakujoudo/shell-next/wiki/Getting-Started)
- [Command lifecycle](https://github.com/gokurakujoudo/shell-next/wiki/Command-Lifecycle)
- [Backend support](https://github.com/gokurakujoudo/shell-next/wiki/Backend-Support)
- [Testing with mocks](https://github.com/gokurakujoudo/shell-next/wiki/Testing-with-Mocks)
- [Troubleshooting](https://github.com/gokurakujoudo/shell-next/wiki/Troubleshooting)
